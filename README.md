## 🤖 Building for agents that run locally

### **⚡ AI agents need a fast private core**

agents can plan and call tools. the missing piece is infrastructure that stays on the machine: memory you can prove, tool calls you can check, and text you can redact without sending it to a vendor.

### **🚀 what i build**

small libraries meant to sit on a hot path:

🧠 **provable memory** — show a fact was stored, or that it never was, without handing over the store  
🔒 **privacy by default** — zkSNARK proofs • confidential compute • no surveillance  
⚡ **local execution** — checks run in-process • no round trip • built for the hot path  
✅ **tool-call integrity** — prove a call matched its schema and a replay matches the log
